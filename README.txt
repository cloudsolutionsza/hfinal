AMAKENGANEHOLDINGS WEBSITE

Every file — every page, style.css, script.js, the favicon files, and both cover images — sits directly in this one folder. There are no sub-folders at all.

GITHUB: upload the CONTENTS of this folder to the root of your repository, so that index.html sits at the very top level of the repo (not inside any sub-folder). Then turn on GitHub Pages for that repo.

NEWSLETTER: the form sends submissions to Formspree (form mgavkwjn). They will appear in your Formspree dashboard.
